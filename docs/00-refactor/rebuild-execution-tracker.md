## EN

This tracker is the execution source of truth for the full rebuild. Every step transition must update status, logs, and commit boundaries together.

### Scope of Completion

- Step 00-08 being marked `已完成` means the rebuild's engineering boundaries, contracts, determinism, authoritative room flow, replay pipeline, and release gates are closed; it does not automatically mean the product already provides a player-ready full board experience.
- The top-level homepage still acts as a validation shell, but product-facing closure is now tracked separately in [`../10-architecture/full-board-ui-roadmap.md`](../10-architecture/full-board-ui-roadmap.md), whose Phase 4-8 gates are now closed.
- Step 08 only reopens the engineering release/tag path. As of 2026-04-18, product-semantic versions `v1.0.0+` are no longer blocked by roadmap Phase 4/8 gates, but release wording must still respect the validated artifact scope in `docs/40-operations/release-prep.md`.
