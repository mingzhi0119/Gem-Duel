## EN

This tracker is the execution source of truth for the full rebuild. Every step transition must update status, logs, and commit boundaries together.

### Scope of Completion

- Step 00-08 being marked `已完成` means the rebuild's engineering boundaries, contracts, determinism, authoritative room flow, replay pipeline, and release gates are closed; it does not automatically mean the product already provides a player-ready full board experience.
- The current default player entrypoint is still a minimal validation shell. Full board UI, player-path acceptance, spectator-visibility guardrails, and Desktop offline distribution remain follow-up work.
- Product-facing closure now follows [`../10-architecture/full-board-ui-roadmap.md`](../10-architecture/full-board-ui-roadmap.md), which sorts the remaining remediation into Phase 0-8.
- Step 08 only reopens the engineering release/tag path. Product-semantic versions `v1.0.0+` remain gated on full-board roadmap Phase 4, and Desktop offline distribution remains gated on Phase 8.
