# Buff Taxonomy

Classify every Buff in docs and metadata using these axes.

## Rarity

- `common`
- `rare`
- `boss`
- `meta-unlock`

## Scope

- `self`
- `opponent`
- `global-run`

## Trigger Style

- `passive`
- `triggered`
- `replacement`
- `stacking`

## Lifecycle

- Match-only
- Run-only
- Meta-unlock gate

## Documentation Minimum

Each Buff note should state:

- `id`
- rarity
- scope
- hook point
- effect atoms used
- stacking rule
- replay impact
